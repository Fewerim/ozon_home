# Консольный таск-трекер

Интерактивное приложение для управления задачами. Запуск из каталога `task_1`:

```bash
make run
```

Команды вводятся после запуска программы. Дедлайн задаётся в формате `ГГГГ-ММ-ДД`. Данные сохраняются в `data/data.json`.

Проверки:

```bash
make check
```

## Команды

| Команда | Действие |
| --- | --- |
| `add --title="Купить хлеб" --deadline="2030-01-15"` | Создать задачу. |
| `get-list [--status=planned] [--exited] [--search="хлеб"]` | Показать задачи; флаги нужны для фильтров и они необязательны. Флаг `--exited` показывает только просроченные задачи. |
| `get --id=1` | Показать задачу по ID. |
| `update --id=1 --title="Новый заголовок"` | Изменить заголовок и/или дедлайн (`--deadline="2030-02-01"`). |
| `change-status --id=1 --status=done` | Изменить статус. |
| `delete --id=1` | Удалить задачу. |
| `import --path="examples/import_tasks.json"` | Импортировать задачи из JSON-файла. |
| `help` или `help <команда>` | Показать список команд или справку по команде. |
| `exit` | Завершить работу. |

Статусы: `planned`, `in_progress`, `done`, `canceled`. 

## Дополнительные задания

Реализованы поиск по подстроке в заголовке без учёта регистра (`--search`) и импорт из JSON. При импорте корректные задачи сохраняются, а ошибки остальных выводятся с номерами элементов файла. Пагинация и юнит-тесты не реализованы.

## Архитектура

Приложение разделено на три слоя: `internal/app/transport/cli` принимает команды и выводит результат; `internal/app/service` вместе с `internal/core/domain` выполняет бизнес-логику; `internal/app/repository` хранит задачи в файле или в памяти. `cmd/todo/main.go` собирает слои и запускает приложение.
